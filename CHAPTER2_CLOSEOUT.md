## Next dependency, not another parallel example

The highest-payoff missing proof is **compositional output representation for unbounded pieces when the whole-hull guard fails**. The fixed finite affine reciprocal now has exact generated domain pieces, with zero retained as undefined and no finite range claimed near the pole. The finite guarded representation and its successful-evaluator composition are now constructed. Existing relational and guarded evaluators already establish scoped operator results and must be reused, not rewritten. The remaining integration extends this generated descriptor bridge beyond successful whole-hull guards: each additional supported operator must retain the same input witness, generate its own domain constraints, and prove the joint enclosure/classification result; merely assuming those facts does not close §2.11. Broader nonlinear/exceptional cases require either a supported representation theorem or explicit specification, not new FP assumptions.

The source inconsistencies above require a documented scope/interpretation decision, not more automation. Unspecified rows require primary-source evidence. Ordinary proof gaps can be advanced independently. None of these categories is silently waived to declare the chapter finished.
